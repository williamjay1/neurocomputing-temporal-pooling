# Temporal pooling in neural forecasting: code and evidence

Research code and current core evidence for *Diagnosing temporal pooling in neural forecasting: predictive information and loss geometry* (target journal: Neurocomputing).

**Sole author:** Junjie Zhang. Shanghai Academy of Global Governance & Area Studies and School of Economics and Finance, Shanghai International Studies University. ORCID: https://orcid.org/0009-0004-8821-4018 . Contact: junjiezhang2024@shisu.edu.cn.

The study asks which temporal coordinates predict the required forecast endpoints. It combines exact conditional-risk calculations with matched neural controls; it is not a new N-HiTS architecture, universal retention policy, or successful compression codec. Original real primary intervals include zero. All adverse and source-gated results remain in the release.

## What is included

- A frozen, attributed 80-customer UCI panel with label/activation/DST validity records, roster, splits, source training/validation arrays and fixed minibatch draws.
- All36original real source-selected fits, full calibration/confirmation predictions and simple reference forecasts; all30synthetic fits and synthetic predictions.
- Independent scoring, paired customer/week inputs and outputs, exact risk calculations, nonlinear and same-target loss-boundary examples, multiplicity adjustments and crossed REML sensitivities.
- All120source-only complete-input extension fits and independently reconstructed source losses. Both families failed the frozen competence gate; no external forecasts were produced for them.
- Three main figures and four table artworks, editable SVG/PDF and native1000dpi PNG, with plotting inputs and verified captions/geometry records.
- Original script bytes, chronological protocols, actual installed environment records, public provenance/checksum manifests and portable verification tooling.

The provider ZIP, expanded provider text, installed runtimes, old nested evidence ZIPs and private review/chat files are excluded. Historical full experiments are preserved locally and distinguished from this public current core. The complete journal draft is supplied to the author separately; it is not presented here as an accepted or human-reviewed publication.

## Reproduce

Use Python3.12. The pinned files record the actually observed environment; a clean installation on a different operating system is not silently claimed. Follow `reproducibility/README.md` for actual commands and verification coverage. The runtime adapter maps original archival paths to this checkout without editing original producer bytes and writes fresh checks under `reproducibility/runs/`. It does not overwrite frozen evidence or train new models. Run the lightweight verification first, then the full scoring mode if needed.

Generated portable-check reports state exactly which stages were executed. Stored original audit reports refer to their original scientific draft hashes; the publication metadata revision and current source/payload manifests are separate. Author metadata updates do not alter the primary scientific results. No local code/ZIP is presented as a public DOI.
